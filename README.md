# 🎬 Netflix Clone (Frontend Only)

This is a Netflix landing page clone built using **HTML** and **CSS**. Inspired by the original UI, the goal is to practice frontend design skills including layout, typography, and responsiveness. JavaScript functionality will be added in future versions.

## 🚀 Features

- 🎨 Pixel-perfect clone of Netflix's landing section
- 💌 Email input field with styled placeholder & label
- 🔴 “Get Started” button with hover effects
- 💡 Built with semantic HTML and clean CSS

## 🛠️ Tech Stack

- HTML5
- CSS3 

## ✍️ Future Improvements

- Add form validation with JavaScript
- Animate UI elements
- Add footer & other Netflix sections

## 🧠 What I Learned

- Working with labels inside inputs (floating label design)
- Responsive design using rem/em units
- How to push project structure to GitHub
- Better understanding of real-world layouts
